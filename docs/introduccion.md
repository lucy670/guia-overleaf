# Introducción a LaTeX

Overleaf facilita el uso de LaTeX sin tener que instalar nada en tu ordenador.

??? question "¿Por qué es difícil LaTeX?"
    Al principio puede asustar porque no es un procesador de texto visual (como Word), 
    sino que se parece más a programar. Pero el resultado visual es mucho más profesional.

!!! tip "Consejo"
    No te preocupes por memorizar todos los comandos, Overleaf tiene autocompletado.
