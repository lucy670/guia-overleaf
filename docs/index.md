# Bienvenidos a la Guía de Overleaf

Esta documentación te enseñará a utilizar **Overleaf**, el editor de LaTeX colaborativo más popular del mundo.

![Logotipo de Overleaf](img/logo.png)

## ¿Qué aprenderás aquí?

* Cómo crear una cuenta gratuita.
* La estructura básica de un documento LaTeX.
* Trucos para editar fórmulas matemáticas.
